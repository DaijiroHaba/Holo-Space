# 空想スカウター / HOLO PLAY 01

[公開ページ](https://daijirohaba.github.io/Holo-Space/scouter/) · [HOLO / SPACE](https://daijirohaba.github.io/Holo-Space/)

大学生向けの、ランダムな空想プロフィールで遊ぶカメラ展示です。性格診断や能力測定ではありません。顔の位置を表示枠に使い、性格・タイプ・一言・数値・相性は画像から独立した乱数で決めます。

## 遊び方

1. Chrome / Edgeで公開ページを開き、「カメラで遊ぶ」を押してカメラを許可。
2. 明るい場所で顔を正面に向け、互いに少し間隔を空けます。最大10人分の枠と番号を表示します。
3. 自分の番号と同じカードを見ます。画面内でも約5.5秒ごとに1人の紹介が切り替わります。
4. カードを押すと詳細。「みんなを引き直す」でタイプ・一言・パワー・相性を再抽選します。
5. 「終了」でカメラ・認識処理を停止し、その回の表示を消します。別タブへ移動してもカメラは停止します。

カメラなし体験では1・5・10人の**架空の人物**で画面を試せます。これは認識率のデモではありません。鏡表示・全画面表示・カメラ選択にも対応しています。

## ランダムな設定

- 24タイプ：まじめなユーモア係、さみしがりな頑張り屋、静かなアイデア係など。
- 16の一言：宝箱を開ける前にまず拍手する、小さな成功にも心の中でファンファーレなど。
- 8つの相性設定：宝箱開封委員会、おやつ補給部、こつこつ応援チームなど。
- 遊びパワーと3つの遊び指標も乱数です。順位付け、健康・知能・容姿の評価はしません。
- 相性はランダムな2人組。奇数の時は最後を3人組にして、誰かが余らないようにします。本当の人間関係を判定しません。

## 認識と負荷

MediaPipe BlazeFaceで顔の位置だけを検出。顔照合・個人識別・見た目からの性格推定は行いません。位置と移動の連続性で番号を一時保持します。交差・遮蔽・退出では番号や設定が変わる場合があります。

小さな顔向けに全画面と重なりのある正方形タイルを検出し、重複枠を除去します。認識画像は元のカメラ映像で、照準や文字を含みません。顔が小さすぎる、暗い、横向き、隠れている場合は見落とします。表示上限10人は、あらゆる撮影条件で10人認識を保証する値ではありません。

認識は専用Worker内でCPU実行し、同時処理は1フレームまで。処理時間に合わせて送信間隔を延ばします。描画は約30fps上限。元のHOLOの3D模型・手・姿勢モデルはこのページで読み込みません。モデルとWASMの初回取得には通信が必要です。

## プライバシー

カメラは明示的な開始後に使用します。録画、画像・検出位置の保存、画像アップロードは実装していません。顔の位置とプロフィールはブラウザーの一時メモリで扱い、終了時に破棄します。ページ・認識モデルの配信元はGitHub Pagesです。展示する際は、撮影範囲、端末内処理、ランダムな遊びであることを来場者へ案内してください。

## 検証（2026-10-15）

- 既存HOLOの回帰テスト：88件成功。新機能の単体テスト：9件成功。プロフィールの独立性・変化、最大10枠、重複除去、短い欠落、番号順序、相性の全員参加を確認。
- Edgeの仮想カメラを用いたブラウザーテスト：12項目成功。5・10人デモ、詳細、引き直し、スマートフォン幅、終了、再起動、許可拒否からの復帰、Worker、外部送信なしを確認。
- 人がいない仮想カメラ：40フレーム後も表示0。
- 実モデルと公式対照画像：単一の顔で1枠。同じ画像の顔を10個並べた**合成コラージュ**で20回中20回とも10枠。確認時間を経た追跡状態でも10枠を保持。実際の10人での検証ではありません。
- このホストの仮想カメラで末尾フレームの推論約60～63ms、Worker往復約62～66ms。合成10顔の初回検出約116ms。実カメラの総遅延や他PCの速度を示す値ではありません。
- 検証用ブラウザー全プロセスのprivate commit合計は、空の起動時約108～110MiB、カメラ処理時約646～647MiB。OS全体のRAM使用量・このページだけの実メモリではありません。実機の16GB PCでの動作は未確認です。
- 初期実装では、縮小した10顔を検出できませんでした。正方形タイルへ変更して対照画像で改善を確認しました。参考動画のモニター内の顔は、初期の検出試験で0件であり、成功例として扱っていません。

**未確認：実カメラの5～10人、別PC、混雑時の番号維持、照明・距離・顔の向きごとの認識率。** 公開用ソースには参考動画、参照静止画、実ランドマークを含めません。今回の遊び機能についてClaude監査は実施していません。

現地確認は、まず1人で表示→3人→5人以上の順に増やし、番号の数、見落とし、交差時の入れ替わりを確認してください。重い時は他タブを閉じ、同時にHOLOのカメラを使わないでください。

## 開発者向け

既存ルートで `node server.mjs` を実行し、`http://127.0.0.1:8796/scouter/` を開きます。単体テストは `node --test scouter/tests/unit.test.mjs`。開発者コンソールの `scouterSnapshot()` は人数・処理時間・状態と空想プロフィールだけを返し、生画像・座標・実属性は返しません。
