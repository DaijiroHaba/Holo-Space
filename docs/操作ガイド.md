## 共有URL
- 体験する：https://daijirohaba.github.io/Holo-Space/
- この操作ガイド：https://daijirohaba.github.io/Holo-Space/guide.html

URLを共有するだけで体験できます。インストールとGitHubログインは不要です。カメラを使わず、マウスで模型を見ることもできます。

## 体験の準備
1. カメラ付きPCでChromeまたはEdgeから体験URLを開きます。PC向けに確認した試作版です。スマートフォンや他ブラウザの動作は未確認です。
2. 解剖モデルの読み込みが終わるまで待ちます。初回はモデルと手指認識用ファイルの読み込みに時間がかかります。
3. 「カメラで体験」を押し、このサイトのカメラ使用を許可します。別アプリがカメラを使用している場合は先に閉じます。
4. 手と指先が画面内に収まり、背景と区別できる明るさで使います。つまむ前に、指を一度開いてください。

## 最初の一連の操作
1. 開いた手を3秒かざします。光の円が満ちるとメニューが開きます。
2. 指先カーソルを「人体を呼び出す」へ合わせます。
3. 親指と人差し指を1回つけ、離します。これが「タップ」です。2回タップは不要です。
4. 模型の光る枠内で指をつけて保持すると、模型をつかめます。水色は検出、金色はつまみの認識、桃色は実際につかめた状態です。
5. 手を動かすと模型が移動し、指を離すと位置を保持します。
6. 「操作を停止」「中央へ戻す」「メニューへ戻る」は、手のタップでもマウスでも選べます。

## 回転から移動・拡大へ
1. 模型を表示し、両掌を画面内で正面へ向けて約0.7秒静止。「回転準備」の円が満ちると回転開始。胸〜肩の高さで使えます。
2. 発光している掌で模型を回します。親指・人差し指が近づいても、回転担当の手から別操作へ切り替わりません。
3. その掌をこぶしにして「固定」。手を開き直すだけでは回転を再開しません。
4. 指を開いてから、模型の広い光る枠で片手をつまむ→もう片手を追加。「片手で保持」から「両手で移動・拡大」へ。
5. 移動・拡大し、離して配置。両掌を改めて約1秒保持すると回転へ戻ります。一瞬開いただけでは切り替わりません。

固定後、移動せず回転を再開する場合は、両手を一度軽く握る→開いて保持するか、「掌で回転」を1回タップします。
回転中の担当手ではアイコンを選べません。掌を静止させてもう片手でタップするか、こぶしで固定してからタップしてください。
最新版の目印は「HAND INTERACTION · 11」。古い表示ならCtrl＋F5で再読み込みしてください。

## 操作モード
| モード | 手の動きと模型の動き |
|---|---|
| つかんで移動 | 光る枠内でつまんで保持し、上下左右へ移動。手をカメラへ近づけると手前へ来て大きく見え、遠ざけると奥へ行き小さく見えます。離すと配置します。 |
| 掌で回転 | モードを1回タップで選び、開いた掌を左右・上下へ動かします。手を止めると回転も止まります。操作している掌をこぶしにすると、その角度で固定します。回転中の親指・人差し指の接触は、移動・パネル取得・モード変更へ渡しません。 |
| 移動・拡大（角度固定） | こぶしで固定した後、指を開いて片手ずつつまみます。共通方向で移動、間隔で拡大縮小、共通前後で奥行き移動。角度は変わりません。離すと配置を保持します。 |
| 両手で自由操作 | モードを選び、両手を一度開いてから光る外枠の左右をつまみます。両手の中点で移動、両手共通の前後で奥行き、前後差で立体的な回転、間隔で拡大縮小、結ぶ線の傾きで模型を傾けます。 |

前後操作中や掌を傾けすぎたときは、間隔による倍率変更を保留します。前後を落ち着かせ、掌をカメラへ向けてから間隔を変えてください。奥行きと倍率を同時に変えようとすると分離が難しいため、前後を優先します。

## 動かせる操作画面
右側のモード群は、上端の「ここをつまんで移動」をつまんで配置できます。マウスでも上端をドラッグできます。右上の矢印で端の既定位置へ戻します。
浮遊する解剖パネルは上の帯をつまんで移動します。模型とは独立して配置できます。操作パネルの移動開始時とUIボタンへの操作中は、模型の動きを停止します。
模型を保持している間は、別の手でのUIタップが操作を奪わないようにします。先に離してからタップしてください。回転を担当している手のつまみはUIへ渡しません。回転を止めてからもう片手でアイコンをタップするか、こぶしで固定して操作を引き継ぎます。パネルの移動は回転以外のモードで行ってください。

## 表示・停止・復帰
- 筋肉・骨格・臓器はメニューから切り替えます。通常は1体です。「表示設定」で3体比較表示を選べます。
- 「操作を停止」で人体の角度を固定します。指を一度開き、枠内からつまむと角度を保った移動・拡大へ進めます。
- 「中央へ戻す」は選択中の対象の位置・向き・倍率を初期状態へ戻します。
- 「没入表示」で説明などを隠せます。「操作画面を戻す」は手のタップでも選べます。
- 追跡喪失時は停止し、再検出だけでは再開しません。回転・角度固定モードは一度指を開いて新しくつまみます。つかんで移動・自由操作モードでは同じモードをタップして再開します。
- 配置はページを開いている間保持します。再読み込みすると初期化します。部屋の実空間への固定ではありません。

## マウス操作
| 操作 | 結果 |
|---|---|
| アイコンをクリック | 呼び出し・表示切替・モード・停止・復帰 |
| 模型をドラッグ | 回転 |
| Shift＋模型ドラッグ | 上下左右へ移動 |
| ホイール | 拡大・縮小 |
| Alt＋ホイール／ドラッグ | 相対奥行き移動 |
| 浮遊パネル、操作パネル上端をドラッグ | パネルだけ移動 |

マウスで操作した後も手の操作へ戻れます。切替のための再起動は不要です。

## うまく動かない場合
- カメラが始まらない：アドレスバー付近のサイト設定でカメラ許可を確認し、他のカメラ使用アプリを閉じます。学校・職場の端末ポリシーで制限されている場合は管理者へ確認します。
- タップが決まらない：指を一度開き、カーソルをボタンへ合わせてから、つけて離します。指先が隠れないようにします。
- つかめない：光る枠内とその近傍でつまみます。桃色になったことを確認してから動かします。
- 両手が重なる／対象が止まる：両手を離し、開いてから取得し直します。
- 回転を止めたい：「操作を停止」をタップします。手を見失った場合も停止します。
- 初回読み込みが遅い：ファイル取得が完了するまで待ちます。ネット接続や端末の描画性能の影響を受けます。

## 映像・利用条件・確認範囲
カメラ映像と実際の手指座標は端末内で処理し、アプリは録画・アップロードしません。ページと配布ファイルの取得にはGitHub Pagesへの通常の通信があります。
教育・体験用の試作版です。単眼カメラの奥行きは相対操作用の推定です。診断、治療、姿勢矯正の効果、正確な実距離を検証したものではありません。
停止・引き継ぎを追加したv0.10のClaude監査はPASS_WITH_MINOR_ISSUES（主に入力・状態遷移を確認）。v0.11では回転担当の手によるUI取得を追加修正し、単体72件と合成ブラウザの回帰試験で確認しています。今回の追加修正への新たなClaude監査は実施していません。実人物の手での成功率、照明ごとの認識、実カメラの遅延は未確認です。
