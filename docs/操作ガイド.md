# HOLO / SPACE 操作ガイド
2026-10-23 / 公開版 v0.17.1

## 共有URL
[アプリを開く](https://daijirohaba.github.io/Holo-Space/) / [GitHub](https://github.com/DaijiroHaba/Holo-Space)
PCのChrome/Edgeで開きます。更新が古い場合はCtrl＋F5を押し、HAND INTERACTION · 17.1を確認してください。

## マウスなしで始める
1. 「カメラで体験」を押し、カメラを許可します。肩と手全体が映る明るい場所で使います。
2. 一人で映っていれば、短い安定確認で自動固定します。「候補」「この人に決定」を押す必要はありません。
3. 複数人が映る場合は、操作する人だけが胸の高さで掌を約1秒開いてください。複数の人が同時に掌を開くと確定を待ちます。
4. 使う手を一度開いて約3秒かざすとメニューが出ます。最初に使う手が主操作手になります。両手を同時に見せる必要はありません。
5. アイコンへ指先カーソルを合わせ、親指と人差し指を一度つけて離すと選択します。

手動の候補・確定ボタンは補助として残しています。人物候補が上限の4人に達した場合は操作を止めます。アプリを前面にして操作してください。別タブでの待機中は配置を保って止まり、戻ると新しい人物確認と開指から再開します。

## 模型を動かす
光る大きな枠の中でつまむとつかめます。主操作手を動かすと移動し、離すと配置します。手をカメラへ近づけると手前へ大きく、遠ざけると奥へ小さく見えます。
通常は1体。筋肉・骨格・臓器を切り替えます。3体比較は「表示設定」から任意で選べます。選んだ模型だけを動かします。

## 回転を止めて大きく見る
「掌で回転」を1回タップし、主操作手の掌を動かして回します。掌を止めると停止、こぶしにすると固定します。指を近づけても勝手につまみ移動へ切り替わりません。
固定後に主操作手でつまみ、もう片手を加えると、角度を保って移動・拡大できます。両手の間隔を広げる／狭めると拡大／縮小。同方向へ動かすと移動。自由に傾けたい場合だけ「両手で自由操作」を選びます。
通常のメニュー・掌回転・こぶし停止は主操作手だけ。補助手は両手モードの模型操作だけに参加します。

## パネル・停止・戻る
浮遊パネルの上端と操作パレットの帯をつまむ／マウスでドラッグすると、個別に移動できます。パネルは回転しません。
「操作を停止」「中央へ戻す」「メニューへ戻る」は下部にあります。没入表示からは「操作画面を戻す」で復帰します。マウス操作の後も手の操作を続けられます。
両手モードでつかみを放し、両掌を開いて離してから一回拍手すると表示と配置を初期化します。つかみ中にはリセットしません。音は使いません。選択人物は維持します。

## 手や人物を見失ったとき
模型は最後の配置で止まり、短く「確認中」と出ます。戻ったら少し安定させ、一度指を開いてから新しくつまんでください。掌回転はモードを選び直します。
一時的な推定の揺れでは配置を保って確認を待ちます。長く退出して再選択が必要な場合は、操作する人が胸の高さで掌を約1.5秒開くか、補助の「選び直す」を使います。手をつまんだまま戻しても操作を自動再開しません。
標準の人物限定が使えない場合、「手のみ・他人も反応（軽量）」は明示的な任意選択です。このモードでは他人の手を除外できません。人物限定から勝手に切り替わることはありません。

## 反応しないとき
「認識チェック」で、手の検出・人物選択待ち・認識処理の失敗を確認してください。手全体を画面内へ近づけて開く→CPUで試す→3Dを止めて比較、の順で切り分けられます。
全身映像では手首周辺の拡大認識も行います。床や模型は表示だけで認識画像には入りません。模型自体の描画・メモリ負荷は残るため、16GBのPCでも他アプリやGPU、電源設定により動作が異なります。メモリ量だけでは原因を確定できません。

## 映像・確認範囲
映像は端末内で処理し、アプリは録画・アップロードしません。ページとモデルの取得はGitHub Pagesへの通信です。
合成入力と仮想カメラの検証に加え、一台の実カメラで自動固定・手追跡・メニュー・模型呼び出しを画面確認し、移動・掌回転・こぶし停止・両手拡大は利用者の一連の成功報告を得ました。認識率の測定ではありません。別PC・複数人・拍手成功率・長時間メモリ・実動作の遅延は未確認です。顔認証ではなく、完全な個人識別を保証しません。完全遮蔽・同じ位置での人物交代・他人の肩や手首の欠測・Poseの左右誤判定には限界があります。
教育用の非商用体験版です。実距離や医学的姿勢評価を示すものではありません。[出典と利用条件](ATTRIBUTION.md) / [詳しい操作仕様](OPERATION_SPEC.md)
