# HOLO / SPACE 操作ガイド
2026-10-07 / 公開版 v0.15
## 共有URL
[アプリを開く](https://daijirohaba.github.io/Holo-Space/) / [GitHub](https://github.com/DaijiroHaba/Holo-Space)
インストール不要。PCのChrome/Edgeを推奨。古い画面ならCtrl＋F5、HAND INTERACTION · 15を確認。
## 準備
カメラに顔・肩・手が映るように、中央に一人で立ちます。カメラを許可し、読み込みを待ちます。明るい場所で背景と手を区別できるようにします。
## 主操作手を選ぶ
使う手を開いて約3秒かざす→メニュー→その手の親指と人差し指を1回つけて離し、人体を選択。
最初に認識しやすい手を主操作手として固定。通常のタップ・移動・掌回転・こぶし停止はその手だけ。左右の検出順で手を切り替えません。
両手は通常モードでも追跡します。片手で開始でき、補助手は後から追加できます。位置の連続性を中心に追跡し、左右ラベルや肩・手首は補助に使います。個人を識別する仕組みではありません。密接に重なる複数人での完全な識別は保証しません。
## 回転と固定
主操作手で「掌で回転」を1回タップ。その掌を動かして回転し、止めると停止。主操作手をこぶしにすると固定。もう片方のこぶしには反応しません。
開き直すだけでは回転を再開しません。再開は「掌で回転」をタップ。
## 両手で操作
「両手で移動・拡大（角度固定）」と「両手で自由操作」のときだけ、追跡済みの補助手も模型操作に参加します。主操作手で広い光る枠をつまみ、もう片手を追加。最初の取得やボタン操作は主操作手です。
共通方向で移動、手間隔で拡大縮小、共通前後で奥行き。角度固定モードは向きを保ち、自由操作では傾き・前後差で回転。
カメラへ近づけると手前で大きく、遠ざけると奥で小さく。離すと配置を保持。
## 拍手で全リセット
両手モードで指を離し、両手を開いて離した状態から1回拍手。模型・浮遊パネルの配置と倍率、選択、比較表示、操作パレット、没入表示を初期化し、最初の3秒召喚画面へ戻ります。カメラは継続します。
音を聞く機能は使わず、指を伸ばした両掌が速く接近する動きで判断。短い重なりや、準備後の一時的な指の接近でも判定を続けます。つまみ中の拡大縮小、ゆっくりした接近、片手モードではリセットしません。
## 浮遊パネル
パネルの回転はすべて無効。手・マウスでも正面を維持し、移動・奥行き・拡大縮小のみ。パネル選択中は掌回転ボタンを無効化。
パネル上の帯とモードパレットの上端をつまむ／ドラッグして配置。中央へ戻す操作も使用できます。
## 停止・戻る・操作者変更
停止・中央・メニューは下部。没入表示からは「操作画面を戻す」で復帰。マウス操作後も手の操作を継続できます。
主操作手が消えたら「手を確認中」として模型を止め、役割・モード・配置を保持します。短い欠落から戻ると現在の配置を基準に再開。長い欠落ではつかみだけを解放するので、元の場所付近で手を見せ、一度指を開いてつまみ直してください。肩の欠落だけでは解除しません。
操作者を意図的に交代する場合は、表示設定の「操作者を選び直す / 全リセット」を使います。追跡不足のたびに再設定する必要はありません。

## 別PCで手が反応しないとき
Ctrl＋F5で更新し、HAND INTERACTION · 15を確認。「カメラで体験」を押し、表示設定で使用するカメラを選びます。
「手を確認中」なら、元の位置付近で手全体を開いて見せます。両手を同時に見せる必要はありません。肩が一時的に消えても追跡を続けます。複数の手が重なった場合は離して見せてください。
全身が映って手が小さい場合、元videoの手首周辺を384pxに拡大して両手を補完認識します。極端に小さい手やぶれ・遮蔽は拡大しても復元できません。一歩近づくか、手を明るく照らしてください。
床・模型・UIは認識画像に含めていません。床の模様変更自体は手の認識入力を変えません。
## 短い実機確認
1. 片手を3秒かざす→タップで模型→後からもう片手を見せる。
2. 主操作手で移動。補助手だけのタップやこぶしで操作が変わらないか確認。
3. 主操作手を一瞬隠して戻す。配置が飛ばず、操作者再設定を求められないか確認。
4. 掌回転→主操作手のこぶし固定→片手から両手つまみ→角度を保って拡大。
5. 指を離して配置→両手を開いて拍手→初期画面。パネル移動、停止、中央、メニュー、没入からの復帰も確認。
別PCのライブ操作性と実カメラの成功率は未確認です。合成テスト成績を実際の認識率として扱わないでください。
