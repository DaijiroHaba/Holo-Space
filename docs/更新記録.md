# v0.11 更新記録
2026-10-06。

## 改善
v0.10の回転停止・こぶし固定・角度固定の移動拡大を公開版へ反映。
回転担当の手がパレット上端でつまむとパネル取得が優先される不具合を再現し、修正した。担当手のつまみを模型・パネル・UIへ渡さず、回転中は対象取得も遮断する。静止した掌を見ながら、もう片手でUIをタップする導線は維持。
アプリ入口と操作モジュールのURLに版番号を付け、更新後に古い操作コードを参照することを抑える。

## 監査
v0.10の独立Claude監査はPASS_WITH_MINOR_ISSUES。主に入力と状態遷移の確認で、全ファイルの逐行確認ではない。指摘への修正と該当経路の自己検証を実施済み。
今回のv0.11追加修正は自己検証のみ。新しいClaude監査は依頼されておらず、実施していない。CLAUDE_AUDIT_RECOMMENDED。コード監査を実カメラの動作確認とみなさない。

## 体験
両掌を短く保持→掌で回転→操作掌をこぶしにして固定→指を開いて片手ずつつまむ→角度を保って移動・拡大→離して配置→両掌で再回転。
固定後、移動せず再開する場合は両手を一度軽く握って開くか掌モードをタップ。回転担当の手ではUIをタップしない。
