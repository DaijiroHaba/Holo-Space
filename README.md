# HOLO / SPACE v0.12
2026-10-07。主操作手固定・一人分の姿勢照合・パネル回転禁止・拍手リセットを追加。
カメラに顔・肩・手を映し、使う手だけを3秒かざしてください。通常と掌回転はその手だけ。両手モードだけ補助手を使用します。
掌回転はボタンを1回タップ。主操作手のこぶしで固定。両手で移動・拡大し、離して1回拍手すると初期画面へ戻ります。
パネルは回転せず正面を維持。操作者が入れ替わったら表示設定の「操作者を選び直す / 全リセット」。
[公開アプリ](https://daijirohaba.github.io/Holo-Space/) / [操作仕様](OPERATION_SPEC.md)
最新版の目印はHAND INTERACTION · 12。古い表示ならCtrl＋F5。
