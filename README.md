# HOLO / SPACE v0.17
[公開アプリ](https://daijirohaba.github.io/Holo-Space/) / [操作ガイド](https://daijirohaba.github.io/Holo-Space/guide.html) / [操作仕様](OPERATION_SPEC.md)

先に人物候補を選び、安定確認後に「この人に決定」します。選択人物に対応できた手だけを既存操作へ渡します。詳しい仕様・確認範囲は[人物選択と操作仕様](OPERATION_SPEC.md)。

両手を追跡し、通常操作は主操作手だけ。片手を約3秒開いてメニューを出し、親指と人差し指を一度つけて離して選択します。補助手は後から追加可能。短い追跡不足では配置・モード・役割を保持し、手が戻った位置で操作基準を取り直します。
掌回転→主操作手のこぶしで固定→両手つまみで移動・拡大。浮遊パネルは回転しません。両手モードでつかみを離してから拍手すると全リセット。
全身映像では元videoの手首周辺を拡大して補完認識。床や模型は認識画像に含まれません。
目印は HAND INTERACTION · 17。同じ公開URLへ反映する版です。古い表示ならCtrl＋F5。URLは変更していません。

映像は端末内で処理し、録画・送信しません。ページとモデルの取得はGitHub Pagesへの通信です。

## ローカル起動・テスト
Node.jsで `node server.mjs`、http://127.0.0.1:8796/ を開きます。`node tests/run-player-unit.mjs` は今回の現行仕様に対応した合成単体テスト。過去の版番号のテストは履歴として残し、旧仕様の永久操作者解除テストは現行の採用対象外です。

## 手が表示されない場合
「認識チェック」から、掌を大きく映す→CPUで試す→3Dを止めて比較→診断をコピー。手推論の起動、0手の検出、操作者待ちを区別します。
人物限定ではカメラ開始後に候補を選び、「この人に決定」してから手操作を開始します。人物確認が停止した場合に自動で手のみへ切り替えません。手のみは入力欄から明示的に選ぶ任意モードです。GPU手認識の実行時エラーはCPUへ復旧。通常は1体分だけ生成し、3体比較は必要時に生成。実機原因の確定には影響PCの診断結果が必要です。
