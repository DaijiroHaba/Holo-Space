# HOLO / SPACE v0.13
2026-10-07。主操作手固定・一人分の姿勢照合・パネル回転禁止・拍手リセットを追加。
カメラに顔・肩・手を映し、使う手だけを3秒かざしてください。通常と掌回転はその手だけ。両手モードだけ補助手を使用します。
掌回転はボタンを1回タップ。主操作手のこぶしで固定。両手で移動・拡大し、離して1回拍手すると初期画面へ戻ります。
パネルは回転せず正面を維持。操作者が入れ替わったら表示設定の「操作者を選び直す / 全リセット」。
[公開アプリ](https://daijirohaba.github.io/Holo-Space/) / [操作仕様](OPERATION_SPEC.md)
最新版の目印はHAND INTERACTION · 12。古い表示ならCtrl＋F5。
実カメラの操作感・複数人の識別精度は未確認。

別PCで映像だけ出て手が反応しない場合：手の検出状態を表示し、姿勢照合が成立しない初期状態では一人限定の手のみ認識へ移行します。姿勢モデルの障害は手認識を止めません。Claude v0.13監査はPASS_WITH_MINOR_ISSUES、指摘後につかみ中の拍手判定を無効化。実カメラの操作性は未確認。POST_AUDIT_V13.md参照。

別PCの手認識・拍手修正：肩が映らない場合は一人限定の手のみ認識。検出なし・姿勢照合待ちを表示。姿勢モデル障害でも手認識を継続。拍手は両手モードで指を離してから一度速く両掌を近づけます。実カメラの成功率は未確認。
