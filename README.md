# HOLO / SPACE v0.17.2
[公開アプリ](https://daijirohaba.github.io/Holo-Space/) / [操作ガイド](https://daijirohaba.github.io/Holo-Space/guide.html) / [操作仕様](OPERATION_SPEC.md)

カメラを開始し、一人で肩と手を映すと短い安定確認で自動固定します。候補クリックや確定ボタンは不要。複数人なら、操作する人だけが胸の高さで掌を約1秒開きます。両手の同時提示は不要です。

固定後は、片手を約3秒開いてメニュー→アイコンで親指と人差し指を一度つけて離す→光る枠をつまんで移動。掌回転→主操作手のこぶしで固定→両手つまみで移動・拡大。浮遊パネルは回転しません。両手モードでつかみを離してから拍手すると配置をリセットします。通常は1体、3体比較は任意。マウス操作も維持しています。

目印は HAND INTERACTION · 17.2。古い表示ならCtrl＋F5。URLは同じです。別タブに移った間は操作を止め、戻った後は新しい人物観測と開指から再開します。実操作はアプリを前面にして行ってください。

## 大画面・離れた位置での改善（v0.17.2）
人物の固定前から、一人の新しい人物候補の手首を使って拡大認識します。短い人物位置の揺れでは入力を保留し、配置を維持します。処理時間と結果の更新間隔に合わせた有限の鮮度判定を使い、画像取得中に同期の手解析を重ねません。

人物設定は右上へ移し、固定後・模型操作中は人物枠とともに自動で隠します。下部の「操作者設定」で再表示できます。4K画面でも3D描画は約207万ピクセル（1080p）以内に制限します。画面上の操作座標やカメラ解析の解像度は縮めません。解剖モデルのジオメトリとメモリ使用量そのものは削減していません。

今回の確認範囲と限界は[修正記録](RELEASE_V0172.md)を参照してください。

## 起動・検証
Node.jsで node server.mjs、http://127.0.0.1:8796/ を開きます。現行の合成単体は node tests/run-player-unit.mjs。旧版専用テストは履歴として残します。

実カメラで旧版の一人への重なり誤判定を確認し、修正版では自動固定・手追跡・メニューと模型呼び出しを画面確認しました。移動・回転・こぶし停止・両手拡大はWeによる一連の成功報告を得ています。一台での共同確認であり、他PC・複数人・長時間の認識成績や遅延は未検証です。

認識チェックからCPU・3Dなしとの比較が可能。手のみ認識は他人も反応することを表示した任意モードで、自動には切り替えません。3Dのジオメトリ負荷は今回減らしていません。

映像・実ランドマークはPC内で処理し、録画・外部送信しません。ページ・モデル取得はGitHub Pagesへの通常の通信です。教育用・非商用体験版。[出典と利用条件](ATTRIBUTION.md)を参照してください。
