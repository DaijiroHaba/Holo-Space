HOLO / SPACE 操作ガイド

共有URL

アプリを開く / GitHub

インストール不要。PCのChrome/Edgeを推奨。古い画面ならCtrl＋F5、HAND INTERACTION · 13を確認。

準備

カメラに顔・肩・手が映るように、中央に一人で立ちます。カメラを許可し、読み込みを待ちます。明るい場所で背景と手を区別できるようにします。

主操作手を選ぶ

使う手だけを開いて3秒かざす→メニュー→その手の親指と人差し指を1回つけて離し、人体を選択。

最初に認識しやすい手を主操作手として固定。通常のタップ・移動・掌回転・こぶし停止はその手だけ。左右の検出順で手を切り替えません。

顔や個人の識別ではなく、一人分の肩・手首と手の位置を照合する仕組みです。密接に重なる複数人での完全な識別は保証しません。

回転と固定

主操作手で「掌で回転」を1回タップ。その掌を動かして回転し、止めると停止。主操作手をこぶしにすると固定。もう片方のこぶしには反応しません。

開き直すだけでは回転を再開しません。再開は「掌で回転」をタップ。

両手で操作

「両手で移動・拡大（角度固定）」と「両手で自由操作」のときだけ補助手を追加できます。主操作手で広い光る枠をつまみ、もう片手を追加。最初の取得やボタン操作は主操作手です。

共通方向で移動、手間隔で拡大縮小、共通前後で奥行き。角度固定モードは向きを保ち、自由操作では傾き・前後差で回転。

カメラへ近づけると手前で大きく、遠ざけると奥で小さく。離すと配置を保持。

拍手で全リセット

両手モードで指を離し、両手を開いて離した状態から1回拍手。模型・浮遊パネルの配置と倍率、選択、比較表示、操作パレット、没入表示を初期化し、最初の3秒召喚画面へ戻ります。カメラは継続します。

音を聞く機能は使わず、指を伸ばした両掌が速く接近する動きで判断。短い重なりや、準備後の一時的な指の接近でも判定を続けます。つまみ中の拡大縮小、ゆっくりした接近、片手モードではリセットしません。

浮遊パネル

パネルの回転はすべて無効。手・マウスでも正面を維持し、移動・奥行き・拡大縮小のみ。パネル選択中は掌回転ボタンを無効化。

パネル上の帯とモードパレットの上端をつまむ／ドラッグして配置。中央へ戻す操作も使用できます。

停止・戻る・操作者変更

停止・中央・メニューは下部。没入表示からは「操作画面を戻す」で復帰。マウス操作後も手の操作を継続できます。

主操作手や姿勢が消えたら停止し、もう片方や別の人へ自動で渡しません。長い姿勢欠落や大きな身体移動では「操作者を選び直す」表示になります。

表示設定の「操作者を選び直す / 全リセット」で初期画面へ戻り、使う手をもう一度3秒かざしてください。

確認範囲と利用条件

合成入力と仮想カメラで検証。実カメラの成功率、手の個人差、複数人の重なり、拍手認識率、端から端までの遅延は未確認です。

映像は端末内で処理し、録画・アップロードしません。ページとモデルの取得はGitHub Pagesへの通信です。

教育用の非商用体験版。実距離・医学的姿勢評価ではありません。出典・利用条件を参照。

操作仕様

別PCで手が反応しないとき

Ctrl＋F5で更新し、HAND INTERACTION · 13を確認。「カメラで体験」を押し、カメラを許可。表示設定のカメラを確認します。

「手の検出なし」なら明るい場所で手全体を映す。「手を検出」なのに進まなければ、使う手だけを開いて保持してください。肩・手首が映らない場合は、700ms安定後に「手のみ認識」へ移り、続けて3秒召喚します。手のみ認識は必ず一人で使います。

長い追跡欠落は停止します。「操作者を選び直す」で再設定。姿勢モデルが読み込めなくても手認識は継続します。

拍手は両手モードでつまみを離し、肩幅に開いた掌を一度速く合わせます。音や実際の接触ではなく映像上の接近です。実カメラの認識率・別PCでの実操作は未確認。
